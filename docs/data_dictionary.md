# Data dictionary

## Model outputs

| Key | Unit | Meaning |
| --- | --- | --- |
| `tensile_strength` | MPa | Pulling stress at break |
| `elastic_modulus` | GPa | Stiffness (Young's modulus) |
| `compressive_strength` | MPa | Crushing strength |
| `elongation_at_break` | % | Stretch before breaking ("flexibility") |
| `max_service_temp` | °C | Heat-deflection-style softening point; the part sags above it |
| `decomposition_temp` | °C | Onset of chemical breakdown (DSC/TGA) |
| `density` | g/cm³ | Including predicted porosity |
| `thermal_conductivity` | W/m·K | |

Each prediction also has an `uncertainty` (standard deviation across trees) and an `in_situ_fraction` (share of mass
from local resources: regolith, basalt fibre and, for PHB, the binder itself).

## Inputs

| Key | Type | Range | Default |
| --- | --- | --- | --- |
| `binder` | `PHB` \| `PLA` \| `PEEK` \| `LDPE` | | `PHB` |
| `regolith` | `lunar_highlands` \| `lunar_mare` \| `martian` | | |
| `regolith_wt` | float, wt% | 0–80 | |
| `fiber_wt` | float, wt% | 0–15, and `regolith_wt + fiber_wt ≤ 85` | 0 |
| `particle_size` | float, µm (median) | 10–150 | 60 |
| `temperature` | float, °C | −200 to 150 | 23 |

## `backend/data/regolith_composites.csv` (synthetic training set)

6,000 rows, generated by `python -m data.generate_dataset` (fixed seed). Columns: `binder`, `regolith`, `regolith_wt`,
`fiber_wt`, `particle_size`, then the eight outputs at 23 °C with lab-like scatter.

## `backend/data/nasa_reference_points.csv` (NASA measurements)

| Column | Meaning |
| --- | --- |
| `source`, `table` | NTRS ID and the table or slide the value comes from |
| `binder`, `regolith`, `simulant` | Material, our soil category, and NASA's simulant name (LHS-1, LMS-1, LSP-2, MGS-1, JEZ-1, BP-1) |
| `regolith_wt_target`, `regolith_wt_actual` | NASA's target mix, and the measured ratio (TGA/ash) where reported |
| `orientation` | Print direction for 3D-printed coupons (0° / 90°) |
| `temperature_c` | Test temperature |
| `property`, `value`, `std`, `unit` | The measurement |
| `note` | How it was obtained. Glenn values were read from bar and scatter charts (±0.5 MPa, ±1 °C). |
