# Data sources

## Used in this prototype

- **Synthetic training set** (`regolith_composites.csv`), generated by `generate_dataset.py` from
  classic particulate-composite models. See `docs/data_dictionary.md`.
- **Pure-polymer reference values** (PLA, PEEK, LDPE): typical datasheet ranges.
- **Surface temperature extremes** for the environment check: about −173 °C to 127 °C on the Moon and
  about −125 °C to 20 °C on Mars, as commonly cited for mission planning.

## Planned for calibration

- **NASA Technical Reports Server (NTRS)**, https://ntrs.nasa.gov: reports on regolith simulants and
  polymer–regolith composites.
- **NASA Planetary Data System, Geosciences Node**, https://pds-geosciences.wustl.edu: regolith
  composition and physical-property data.
- **Regolith simulant datasheets** (lunar highlands and Mars global simulants): particle density,
  size distribution and mineralogy.
